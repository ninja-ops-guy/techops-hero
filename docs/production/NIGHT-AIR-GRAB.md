# Aerial grab — offline prototype

The explicit grab input (G or the optional GRAB touch control) can catch an
eligible launched opponent when both are airborne, close and facing correctly.
Left/right throw sideways, up throws upward, and down slams. An aerial throw is
a juggle finisher: it locks the opponent against further attacks until landing,
so repeated grabs cannot reset the existing three-contact limit. A player can
be hit out of the hold. Grounded grab behavior remains unchanged. Grabs do not
pull in distant, hovering, ungrabbable, locked, or grounded targets from the air.

The current hold/throw visuals reuse existing poses. Dedicated character-specific
aerial grab and throw animation, real player-versus-player behavior, breakouts,
network synchronization and balance are not qualified. Training browser tests
use an airborne state fixture and keyboard inputs, not a full earned combo or
physical mobile touch. See the full combat roadmap for light/heavy attacks,
gravity cancels and Iona's planned weapons and meter, which remain unfinished.
